# Research Data Management (RDM) & FAIR Principles 🔬📊

Este repositório reúne cadernos de análise de dados, scripts em Python e documentação prática voltados para a **Gestão de Dados de Pesquisa (GDP)**, governança de dados científicos e implementação dos **Princípios FAIR** (Findable, Accessible, Interoperable, Reusable).

## 📁 Estrutura do Repositório

* `notebooks/`: Cadernos Jupyter com análises exploratórias, tratamento e visualização de dados.
* `scripts/`: Rotinas e utilitários em Python para processamento e validação de metadados.
* `docs/`: Guias rápidos sobre Planos de Gestão de Dados (PGD) e padrões de metadados.
